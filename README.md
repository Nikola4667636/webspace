# Космос
Можно открыть: https://nikola4667636.github.io/webspace/index.html

Учебный сайт про космос на Vite (Vanilla + JavaScript). Три страницы: главная, планеты, миссии.

## Что сделано

**ДЗ №1 (сайт в группе)**
- HTML: заголовки, разделы, изображения, ссылки между страницами.
- CSS: своё оформление (цвета, шрифты, отступы), светлая и тёмная темы, адаптив.
- JavaScript, кнопки с разными действиями:
  - «Сменить тему» (запоминается в `localStorage`);
  - «Подробнее» / «Скрыть» у планет и запусков;
  - «Следующая планета» и вкладки планет.

**ДЗ №2 (Vite и API)** — страница «Миссии»
- Данные через `fetch` из публичного API [Launch Library 2](https://ll.thespacedevs.com/2.2.0/launch/previous/) (The Space Devs): последние 60 запусков ракет. Ключ не нужен, CORS включён.
- Интерфейс: поиск (название, ракета, оператор), выбор категории (оператор запуска), кнопка «Обновить».
- Состояния:
  - загрузка — «Загрузка…»;
  - результат — карточки запусков;
  - пустой результат — «Ничего не найдено»;
  - ошибка — понятное сообщение и кнопка «Повторить попытку».
- Проверяется `response.ok`: ответы HTTP 404, 429 и 500 считаются ошибкой.

## Запуск и сборка

```bash
npm install        # установка зависимостей
npm run dev        # режим разработки, http://localhost:5173
npm run build      # сборка в папку dist
npm run preview    # просмотр собранной версии
```

## Публикация на GitHub Pages

Сборка публикуется автоматически через GitHub Actions (`.github/workflows/deploy.yml`) при пуше в `main`.

Достаточно открыть https://nikola4667636.github.io/webspace/index.html в браузере.
