# Космос

Небольшой сайт про космос. На сайте три страницы: главная, планеты и миссии. Написан на HTML, CSS и JavaScript.

## Что есть на сайте

- **Главная** - приветствие, картинка и две ссылки на остальные страницы.
- **Планеты** - вкладки с планетами (Земля, Марс, Юпитер, Сатурн). Можно выбрать планету, показать или скрыть описание и переключиться на следующую.
- **Миссии** - лента событий из истории освоения космоса. Миссии можно фильтровать по типу и раскрывать подробности.
- **Тема** - кнопка "Сменить тему" переключает светлое и тёмное оформление на всех страницах. Выбор запоминается в браузере.

## JavaScript

Кнопки на сайте делают разные вещи:

- смена темы страницы
- переключение планеты по вкладкам и кнопке "Следующая планета"
- показать или скрыть описание ("Подробнее" / "Скрыть")
- фильтр миссий и счётчик показанных миссий

## Структура проекта

```
project/
├── index.html
└── web/
    ├── static/
    │   ├── css/
    │   │   ├── base.css
    │   │   ├── home.css
    │   │   ├── planets.css
    │   │   └── missions.css
    │   ├── js/
    │   │   ├── theme.js
    │   │   ├── planets.js
    │   │   └── missions.js
    │   └── images/
    └── templates/
        ├── index.html
        ├── planets.html
        └── missions.html
```

- `templates` - html-страницы
- `static/css` - стили, `base.css` общий для всех страниц
- `static/js` - скрипты, `theme.js` подключён на всех страницах
- `static/images` - картинки
- `index.html` в корне нужен для GitHub Pages, он перенаправляет на главную страницу сайта

## Как запустить

Достаточно открыть `web/templates/index.html` в браузере. Если установлен VS Code, можно открыть папку проекта и запустить Live Server.
